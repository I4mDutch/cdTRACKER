## Deviations from the spec
- Numeric fields are `type="text" inputMode="numeric"` (not type=number) so invalid input is validated and shown inline rather than silently blanked by the browser.
- ACS/ADR are whole numbers client-side (per "whole numbers"); the server may accept decimals.
- Import preview shows map/agent display names via GET /filters/options catalog (falls back to the id).
- Edit form leaves Time blank when the stored time is exactly 12:00:00 UTC (date-only entries).
- Matches page context line has no manual note (the paginated response has no `sources`).
