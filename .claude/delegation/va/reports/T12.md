## Deviations from the spec
- Existing http tests needed no edits (the `source` column is placed after `startedAt` so existing CSV header assertions still hold).
- Duplicate import rows carry an informational message in `errors` ("Already saved..." / "Same as line N in this file.").
- Import also rejects: duplicate header columns, header-only file, rows with more cells than headers (row-level invalid).
- `firstKills`/`firstDeaths` per-field cap is 100 (2 x maxRoundsPerSide); the real bound is the cross-field check.
- Disclaimer suffix uses the literal spec wording (" Includes N manually entered matches.") even for N = 1.
