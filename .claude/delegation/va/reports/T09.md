## Deviations from the spec
- Env gained two optional rate-limit vars (needed so tests can raise limits without changing the `createApp` signature).
- Switching accounts while signed in (user already has a different puuid) calls `deleteUserMatchData` first so the old account's data does not linger; not in spec.
- `POST /sync` for a user with no linked account returns 409 `not_linked` (spec silent).
- `/dev/login` returns 409 `conflict` if puuid 0001 is linked to a non-demo user.
- Callback failures other than state/cancel (token exchange or getMyAccount fails) redirect to `/settings?error=riot`; missing code -> `error=cancelled`.
- CSV headers use the literal PlayerMatchRecord field names (camelCase) plus `map_name`, `agent_name`, `excluded`; includes excluded matches (with `excluded` set) subject to the filter; CRLF line endings. `puuid` column is the user's own.
- `queueId=all` yields `filter` in responses without `queueId` (so the web client sees it as "no queue filter" in the echoed filter).
- DELETE /share-links/:id on an already-revoked own link returns 204 (repo revoke is idempotent); unknown/foreign id -> 404.
