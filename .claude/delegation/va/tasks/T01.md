# T01: Generate deterministic synthetic Riot fixtures

**Agent:** executor-sonnet · **Depends on:** none · **Wave:** 1

## Goal
A script that writes realistic, internally consistent, **synthetic** Riot-shaped JSON so the whole app
(tests, demo mode) runs without Riot access. No real player names or IDs.

## Owns
- `scripts/generate-fixtures.ts`
- `fixtures/**` (generated output, committed)

## Read-only context
- `packages/shared/src/riot.ts` — the DTO shapes every file must satisfy (import types from `@va/shared`).
- `.claude/delegation/va/PLAN.md`

## Output layout (exact)
```
fixtures/riot/content.json                 RiotContentDto
fixtures/riot/accounts.json                { accessToken: string; account: RiotAccountDto; shard: "na" }[]
fixtures/riot/matchlists/<puuid>.json      RiotMatchlistDto (history newest first)
fixtures/riot/matches/<matchId>.json       RiotMatchDto
fixtures/README.md                         short: synthetic, how to regenerate, edge-case list with matchIds
```

## Requirements
1. Deterministic: seeded PRNG (write a small mulberry32 inline). Re-running produces byte-identical files. Pretty-print with 2 spaces + trailing newline.
2. Content: 8 agents and 6 maps with real display names (Jett, Sova, Omen, Killjoy, Sage, Raze, Reyna, Breach; Ascent, Bind, Haven, Split, Lotus, Sunset), synthetic UUID ids (deterministic, format `xxxxxxxx-xxxx-4xxx-8xxx-xxxxxxxxxxxx`), maps with `assetPath` like `/Game/Maps/Ascent/Ascent`. `version: "fixture-1"`.
3. Accounts: two demo players:
   - `demo-puuid-0001`, gameName `DemoPlayer`, tagLine `0001`, accessToken `fixture-token-0001`, 70 matchlist entries.
   - `demo-puuid-0002`, gameName `OtherDemo`, tagLine `0002`, accessToken `fixture-token-0002`, 15 entries.
4. Each match: 10 players (5 `Red`, 5 `Blue`), the demo player is one of them; other 9 have puuids `synthetic-<matchIndex>-<n>` and gameName `Player<n>`. Matches span the 120 days before 2026-10-01T00:00:00Z, chronologically spaced. `gameVersion` cycles through `release-09.06-shipping-...`, `release-09.07-shipping-...`, `release-09.08-shipping-...` by date. `queueId: "competitive"`, `isRanked: true`, `seasonId` fixed synthetic uuid.
5. **Consistency (critical):** standard match = first to 13 rounds (overtime allowed, e.g. 14-12). `roundResults.length === teams[*].roundsPlayed`; count of rounds with `winningTeam === X` equals team X `roundsWon`; exactly one team has `won: true` (except draws). Each round: 1–8 kill events with ascending `timeSinceRoundStartMillis` (5000–100000), killer and victim on opposite teams, a victim dies at most once per round, 0–2 assistants from the killer's team; each player's `stats.kills/deaths/assists` equals the sum over rounds; `damage[]` entries per kill (receiver = victim, damage 100–160 split into head/body/legshots counts); `stats.score` ≈ sum of round `score` (round score = 150·kills + damage-ish, anything consistent). `bombPlanter` set in ~50% of rounds (a player on attacking team), `bombDefuser` in some of those.
6. Give the demo player 0001 a **planted pattern** so analysis has something real to find: on `Split` their win probability is ~0.30 vs ~0.55 elsewhere; on `Reyna` their deaths per round are clearly higher (~0.9 vs ~0.7). Agent mix for 0001: mostly Jett/Sova/Reyna/Omen, a few others (some with 1–3 matches to exercise low-sample flags).
7. Edge cases for player 0001 (record matchIds in fixtures/README.md):
   - 1 remake: `isCompleted: true`, 3 rounds total.
   - 1 incomplete: `isCompleted: false`.
   - 1 draw: 15-15 with `won: false` on both teams (synthetic; exercises draw handling).
   - 2 matches with `roundResults: []` (no round data).
   - 1 match with `queueId: "unrated"` (included in matchlist; excluded from default analysis).
   - 1 match where player 0001 has 0 deaths.
   - The matchlist contains one matchId listed twice (duplicate API response).
   These count toward the 70 entries.
8. matchIds: deterministic synthetic UUIDs.
9. Add npm script already exists at root: `npm run fixtures` → `tsx scripts/generate-fixtures.ts`. The script writes relative to repo root (resolve from `import.meta.url`), deletes and recreates `fixtures/riot/` first.
