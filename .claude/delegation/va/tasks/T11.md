## Decisions already made
- Manual entries belong to a **user** (not a puuid) and do not need a linked Riot account.
- Unlinking Riot (`deleteUserMatchData`) must NOT delete manual entries. Deleting the user row cascades them.
- Ids: `uuid` pk. The public id is `` `${MANUAL_ID_PREFIX}${uuid}` `` (built by mappers, not stored).
- Duplicate protection: a `dedupe_key` (sha256 hex of `startedAt ISO|mapId|agentId|queueId|roundsWon|roundsLost|kills|deaths|assists`) with a UNIQUE (user_id, dedupe_key) constraint.
- Existing Riot mapper must now set `source: 'riot'`.

## Table `manual_matches`
id uuid pk defaultRandom; user_id → users cascade not null; started_at timestamptz not null; map_id, agent_id, queue_id text not null; patch text null; rounds_won, rounds_lost, kills, deaths, assists int not null; combat_score int null; damage_dealt int null; first_kills int null; first_deaths int null; note text null; excluded text null; dedupe_key text not null; created_at, updated_at timestamptz default now. Indexes: (user_id, started_at); unique (user_id, dedupe_key).

export interface ManualMatchFields {

export function manualDedupeKey(f: ManualMatchFields): string;
export async function createManualMatch(db: Db, userId: string, f: ManualMatchFields): Promise<ManualMatchRow | 'duplicate'>;
export async function updateManualMatch(db: Db, userId: string, id: string, f: ManualMatchFields): Promise<ManualMatchRow | 'duplicate' | null>; // null = not found / not owned; bumps updated_at

/** One transaction; ON CONFLICT (user_id, dedupe_key) DO NOTHING. */

/** PlayerMatchRecord view: source 'manual', matchId `manual-<id>`, puuid `user:<userId>`, outcome via manualOutcome,

export function manualRowToRecord(row: ManualMatchRow): StoredPlayerRecord;
