# T13: Web UI for manual entry and CSV import

**Agent:** executor-sonnet · **Depends on:** none (built against the updated DTO contract) · **Wave:** 5 (manual entry feature)

## Goal
Users can add, edit and delete matches by hand and bulk-import them from CSV. Manual data is always visibly labelled
and can be filtered in or out. Nothing the UI shows lets manual data pass as Riot data.

## Owns
- `apps/web/**`

Existing tests in `apps/web/test/` (fix fixtures for the new required fields).

## Decisions already made
- **Routes (react-router):** `/matches/new` (create form), `/matches/:matchId/edit` (edit form; only for ids starting `manual-`), `/import` (CSV import). Add "Add match" and "Import CSV" buttons on the Matches page header; add "Import" to the main nav after Matches.
- **API client** functions: `createManualMatch(input)`, `getManualMatch(id)`, `updateManualMatch(id, input)`, `deleteManualMatch(id)`, `deleteAllManualMatches()` (body `{ confirm: true }`), `importManualCsv(req: ImportRequest)`, `manualTemplateUrl()` → `/api/manual-matches/template.csv`. Same CSRF header and error parsing as existing mutations.
- **Form** (`src/components/ManualMatchForm.tsx`, used by create + edit): fields map, agent (selects from `GET /filters/options` → `catalog.maps` / `catalog.agents`, not the played-only lists), queue (MANUAL_QUEUES, default competitive), date (`<input type="date">`, default today, max today, min `MANUAL_LIMITS.minDate`), optional time, patch, rounds won/lost, K/D/A, then an "Optional stats" fieldset: ACS, ADR, first kills, first deaths, note (textarea, maxLength). Client-side validation mirrors `MANUAL_LIMITS` (whole numbers, ranges, won+lost ≥ 1, first kills + first deaths ≤ total rounds), errors shown inline next to each field with `aria-invalid` + `aria-describedby`; server `validation` errors shown in a summary at the top. Show derived result live ("Result: Win 13–9"). Explain under the optional fieldset: "Leave blank if you don't know — blanks are treated as unavailable, not zero." Submit → navigate to the match detail. On 409 duplicate show "An identical entry already exists." If the catalog has no maps/agents, show a notice that game content hasn't loaded yet.
- **Import page:** short instructions, a "Download template" link, a table of `MANUAL_CSV_COLUMNS` (name, required, description), file input (`accept=".csv,text/csv"`; reject files > `MANUAL_LIMITS.importMaxBytes` client-side), read with `file.text()`, call `importManualCsv({ csv, dryRun: true })` → preview table: line, status (text badge: Valid / Invalid / Duplicate — not color alone), date, map, agent, score, K/D/A, errors list. Summary counts. "Import N matches" button enabled only when `counts.invalid === 0 && counts.valid > 0` (duplicates are skipped and that is stated). Confirm → `dryRun: false` → success message with count and link to Matches (filter `source=manual`). Long previews: show first 200 rows with a note.
- **Labelling everywhere:**
  - `MatchTable` / Matches page: a "Manual" text badge on manual rows (with `title="Entered manually — not from Riot"`).
  - Match detail for manual entries: a banner "Manual entry — entered by you, not from Riot", the note, created/updated dates, Edit and Delete buttons (delete confirms, then navigates to /matches). Field sources table already handles `'manual'`; render it as "Manual entry". No round timeline (rounds empty) — reuse the existing "Round-level data wasn't provided" notice but phrase it "Round-level data isn't available for manual entries" when `manual` is set.
  - Filter bar: new "Source" select (All sources / Riot only / Manual only) stored in URL params as `source`.
  - Context line on Overview, Agents, Maps, Insights and Score card: when `sources.manual > 0`, append " · includes N manual entries" (with the same title tooltip).
  - Public profile page: when `manualCount > 0`, show "Includes N manually entered matches."
- **Settings:** a "Manual entries" section: count isn't available from an endpoint, so just link to Matches filtered `source=manual`, plus "Delete all manual entries" with a confirm dialog (states it cannot be undone and Riot data is unaffected). Also update the existing unlink copy to say manual entries are kept.
- Signed-in users without a linked Riot account must be able to reach `/matches/new` and `/import` (don't gate those on link state).
