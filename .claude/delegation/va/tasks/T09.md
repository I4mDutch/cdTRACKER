## Decisions already made
- `env.ts`: zod-parsed config: `PORT` (3000), `DATABASE_URL` (optional → PGlite at `PGLITE_DIR` or in-memory), `DEMO_MODE` (default `true` when `RIOT_API_KEY` unset), `RIOT_API_KEY`, `RSO_CLIENT_ID`, `RSO_CLIENT_SECRET`, `RSO_REDIRECT_URI`, `PUBLIC_BASE_URL` (`http://localhost:5173`), `SESSION_TTL_HOURS` (168), `COOKIE_SECURE` (default true unless DEMO_MODE), `RAW_RETENTION_DAYS` (30), `SYNC_INTERVAL_MINUTES` (0 = off). Fail fast with a clear message if non-demo and keys are missing. `.env.example` documents all; no real secrets.
- `app.ts`: `export function createApp(deps: { db: Db; riot: RiotClient; rso: RsoProvider; queue: SyncQueue; env: Env }): express.Express`. `main.ts` wires real deps (FixtureRiotClient in demo mode, HttpRiotClient otherwise), starts scheduler if interval > 0, graceful shutdown.
- Sessions: cookie `va_session` (httpOnly, sameSite `lax`, secure per env, path `/`), token via `createSession`. Middleware `requireUser` → 401 `unauthenticated`.
- CSRF: every POST/DELETE requires header `X-Requested-With: va-web` → else 403 `csrf`. (Plus sameSite cookie.)
- Security headers set manually (no helmet dep): `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`, a strict `Content-Security-Policy` for the mock RSO HTML page.
- Rate limit: tiny in-memory fixed-window limiter per IP+route-group (e.g. 120 req/min general, 6/min for `/sync` and `/riot/connect`) → 429 `rate_limited`.
- Validation: zod schemas for query (filter + pagination) and bodies → 400 `validation`. Filter `queueId` defaults to `'competitive'`; `queueId=all` means no queue filter.
- Errors: one error handler returning `ApiError`; never leak stack traces, tokens, or SQL. Structured JSON logs (`console.log(JSON.stringify(...))`) without tokens/cookies.
- **RSO** (`http/rso.ts`): `interface RsoProvider { authorizeUrl(state: string): string; exchangeCode(code: string): Promise<{ accessToken: string }> }`.
  - `MockRsoProvider`: `authorizeUrl` → `/api/riot/mock-authorize?state=…`; that GET route (demo only) renders a minimal HTML page "Mock Riot Sign On (demo)" with an Approve link to `/api/riot/callback?code=fixture-token-0001&state=…` and a Cancel link with `error=access_denied`. `exchangeCode(code)` returns `{ accessToken: code }`.
  - `RiotRsoProvider`: `https://auth.riotgames.com/authorize?client_id&redirect_uri&response_type=code&scope=openid&state`; token exchange POST `https://auth.riotgames.com/token` with HTTP Basic client credentials, `grant_type=authorization_code`. Access token used **only** within the callback to call `riot.getMyAccount` and is never persisted or logged.
  - `POST /riot/connect` requires body `{ consent: true }` (else 400), records consent time, creates oauth state (`createOAuthState`), returns `ConnectResponse`. Callback: `consumeOAuthState` (invalid/expired → redirect `/settings?error=state`), `error` param → `/settings?error=cancelled`, exchange → getMyAccount → if puuid already linked to a different user → `/settings?error=already_linked` → else `upsertRiotAccount` (shard `na` in v1) → enqueue sync → redirect `${PUBLIC_BASE_URL}/settings?linked=1`.
- `POST /dev/login` (DEMO_MODE only, else 404): get-or-create the single demo user (`is_demo`), link `demo-puuid-0001` (gameName DemoPlayer#0001, shard na, consent now) if not linked, enqueue sync, set session, return MeResponse.
- **Authorization by construction:** every data route loads the session user's riot account and uses *their* puuid; no route takes a puuid parameter. `GET /matches/:matchId` uses `getPlayerMatch(db, matchId, puuid)` → 404 if null. Not linked → data routes return empty results (200) for list/summary endpoints, 404 for detail.
- Data endpoints: load `listPlayerRecords(puuid)` (excluded removed, except `/matches` list which includes them with `excluded` set), apply `filterRecords`, compute with @va/core. Names via `getNameLookup` (fallback: the raw id). Summary trends: `winRate` and `kd` with window 10. Recent: last 10, newest first. Breakdowns: baseline = computeStatLine(filtered); rows via `groupStats` with deltas; sort rows by matches desc. Insights: `generateFindings`, flag dismissed via `listFeedback` (action `dismiss`), `saveSnapshot('insights', ...)`. Score: `computeAnalyzerScore(filtered)` + `window: { lastN: DEFAULT_SCORE_CONFIG.windowMatches }`, `saveSnapshot('score', ...)`.
- `MatchDetailDto.fieldSources`: list at least kills/deaths/assists/rounds (riot), acs/adr/firstKills/firstDeaths/winRate (calculated), performanceScore (unavailable, note "Not provided by the Riot match API"); when no round data, round-derived fields → unavailable.
- `MatchSummaryDto.acs` = combatScore/roundsPlayed; `adr` = damageDealt/roundsPlayed (null-safe).
- CSV export: columns = every PlayerMatchRecord field + `map_name`, `agent_name`, `excluded`; header row; RFC 4180 quoting; **prefix cells starting with `= + - @` with `'`** (CSV injection); `Content-Disposition: attachment; filename="valorant-analyzer-export.csv"`. Then a blank line and a `# column definitions` section is NOT allowed in CSV — instead also support `GET /export.csv?definitions=1` returning a 2-column CSV (`column,definition`).
- Share links: `POST` validates fields ⊆ ShareField, expiresInDays 1–365; url = `${PUBLIC_BASE_URL}/p/${token}`. `GET /public/:token` (no auth) builds `PublicProfileDto` from the owner's own competitive records only, only the selected fields, top 3 agents/maps by matches, plus `disclaimer` = SCORE-free text "Stats from <n> matches between <from> and <to>. Not an official Riot rating." and returns 404 when invalid. Never include riotId/puuid in the public DTO (displayName = user's display_name).
- `DELETE /account-link`: `deleteUserMatchData`, return 204; `MeResponse.link.state` becomes `unlinked`.
- `GET /me` with no session: `{ user: null, link: { state:'unlinked', ...nulls }, demoMode }`.
- `GET /sync/:jobId` scoped via `getJob(db, id, userId)` → 404 for other users' jobs.
