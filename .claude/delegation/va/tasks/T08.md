## runSyncJob rules
1. Load account via `getRiotAccount(db, userId)`; none or state `unlinked`/`consent_removed` → mark job failed (`errorCategory 'not_linked'`) and return.
2. `updateJob(... state 'running', startedAt)`, `setLinkState(userId, 'syncing')`.
3. `getContent(shard)` → `upsertContent` (characters → kind 'agent' id/name; maps → kind 'map', id, name, assetPath).
4. `getMatchlist(puuid, shard)` → `saveRawPayload(kind 'matchlist', sourceKey puuid)`. Dedupe matchIds (keep first occurrence). Skip ids where `hasPlayerRecord(matchId, puuid)` (incremental). `updateJob total`.
5. For remaining ids with bounded concurrency (use `createLimiter` from riot): `getMatch` → `saveRawPayload(kind 'match', sourceKey matchId, retentionDays)` → `normalizeMatch` → if `!ok`: count `failedNormalize`, log issue codes, continue → `upsertMatch(match, rawId)` → `toPlayerRecord`; null → count as failedNormalize (player_missing), continue → `upsertPlayerRecord(record, match.excluded)` → `replacePlayerRounds(matchId, puuid, toPlayerRounds(match, puuid))`. Count `excluded` when `match.excluded`. After each match, `updateJob cursor`.
6. Errors per match: `RiotApiError` `not_found` → count, continue. `auth`/`forbidden` → stop: job failed, link state `sync_failed`, lastError `"Riot denied access. Re-link your account."`. `rate_limited`/`upstream`/`network`/`timeout` (client already retried) → stop: job failed with that category, link state `sync_failed`, lastError `"Riot's API is busy or unavailable. Try again later."`. Progress already stored stays stored (re-running is safe).
7. Success: job `succeeded`, finishedAt; `setLinkState('up_to_date', { lastSyncedAt: now, lastError: null })`; `purgeExpiredRawPayloads`.
8. Never throw out of runSyncJob for expected errors; unexpected errors → job failed `internal`, link state `sync_failed`, rethrow only in `log`.

`toPlayerRounds`: one row per `match.rounds` entry: won = `winningTeam === player.teamId`; kills = kills with killer === puuid; died = any kill with victim === puuid; damage from the round's damage entry (0 if none); firstKill/firstDeath from `kills[0]`; planted/defused from planter/defuser. Empty rounds → `[]`.

SyncQueue: processes jobs sequentially (one at a time across the process — safe and simple); `enqueue` on a user with an active job returns that job (no duplicate run). Scheduler skips accounts already syncing.
