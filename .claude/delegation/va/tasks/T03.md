## Rules
- **wilsonInterval:** n <= 0 → null. Standard Wilson score interval, clamp to [0,1].
- **smoothedRate:** `(successes + priorRate*priorWeight) / (n + priorWeight)`; if n + priorWeight === 0 return priorRate.
- **filterRecords:** pure; exact match on agentId/mapId/queueId/patch when set; `from` inclusive, `to` exclusive (compare `Date.parse`); result sorted by startedAt **ascending** (stable; tie-break matchId); `lastN` (positive integer) keeps the last N after other filters. Undefined/empty-string filter fields are ignored. Input not mutated.
- **computeStatLine:** follow `StatLine` doc comments exactly. Specifics:
  - empty input → all counts 0, all rates null, interval null, zeroDeaths false, coverage zeros.
  - `rounds` = sum roundsPlayed. per-round K/D/A use `rounds` as denominator (null if 0).
  - kd: deaths>0 → kills/deaths; deaths===0 && kills>0 → kills, zeroDeaths=true; deaths===0 && kills===0 → null. kda analogous with (kills+assists).
  - acs: sum combatScore / sum roundsPlayed over records where combatScore !== null; null if none. coverage.combatScore = that count.
  - Round-derived (adr, headshotPct, firstKillsPerRound, firstDeathsPerRound, firstDuelWinRate): only records with `damageDealt !== null` contribute (coverage.roundData = count, coverage.roundDataRounds = their rounds). adr = sum damageDealt / roundDataRounds. headshotPct = hs/(hs+bs+ls) (null if denominator 0). first* per round over roundDataRounds. firstDuelWinRate = fk/(fk+fd), null if 0.
  - Do not round values; presentation rounds.
- **groupStats:** groups by key (records with `patch === null` grouped under key `"unknown"`); returns sorted by matches desc then key asc; `lowSample = matches < config.lowSampleMatches`.
- **computeTrend:** sort ascending as filterRecords does; for each index i ≥ 0 produce a point using the window of records `max(0,i-window+1)..i` (so early points use smaller windows; `sample` = number of records in the window that contribute a non-null value for the metric). value = the StatLine field of that window (`winRate`, `kd`, `acs`, `adr`, `killsPerRound`, `deathsPerRound`) via computeStatLine. window < 1 → throw RangeError.
