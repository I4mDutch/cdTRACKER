## Decisions already made
1. **Loading records:** replace `listPlayerRecords(db, puuid)` usage in `loadFiltered`, `/filters/options`, `/export.csv` and `/public/:token` with `listUserRecords(db, userId, puuidOrNull, opts)`. Users with no linked account still get their manual records. `parseFilter` accepts `source` (`riot`|`manual`; anything else → 400).
2. **`sources` counts** (`{ riot, manual }`) computed from the filtered record set on summary, agents, maps, insights, score.
3. **DTOs:** `MatchSummaryDto.source`. `toMatchDetail` for manual records: `rounds: []`, `teams` = `[{ teamId: 'you', isPlayerTeam: true, roundsWon, won: outcome==='win' }, { teamId: 'opponents', isPlayerTeam: false, roundsWon: roundsLost, won: outcome==='loss' }]`, `durationMs: null`, `fieldSources` = kills/deaths/assists/rounds/map/agent/date → `'manual'`; acs/adr/firstKills/firstDeaths → `'manual'` when non-null else `'unavailable'` ("Not entered"); winRate → `'calculated'`; performanceScore → `'unavailable'`; `manual: { note, createdAt, updatedAt }`. Riot records: `manual: null`.
4. **`GET /matches/:matchId`:** if it starts with `MANUAL_ID_PREFIX`, strip, require UUID format, `getManualMatch(db, userId, id)` → 404 otherwise. Riot path unchanged (still requires linked puuid).
5. **`/filters/options`:** existing lists come from the user's records (both sources); new `catalog` = all `content_items` (agents by id; maps with id = asset path, falling back to id), sorted by name.
6. **Content without Riot sync:** in `main.ts`, at startup, if there are no content items, call `riot.getContent('na')` and `upsertContent` (log and continue on failure). In demo mode this loads fixture content.
7. **Validation (`validation.ts`)** — one zod schema `manualInputSchema` used by POST, PUT and every CSV row, enforcing `MANUAL_LIMITS` and the contract docs: date `YYYY-MM-DD` (→ 12:00:00Z) or ISO date-time; not after now + 24 h; not before `minDate`; mapId/agentId must exist in `catalog` (check after zod; error `mapId: unknown map`); queueId ∈ MANUAL_QUEUES (default competitive); patch `^\d{1,2}\.\d{2}$` or null/empty; rounds 0..maxRoundsPerSide integers, won+lost ≥ 1; K/D/A 0..maxKda integers; acs 0..maxAcs, adr 0..maxAdr (numbers, ≤1 decimal is fine); firstKills/firstDeaths integers ≥0 with fk+fd ≤ won+lost; note ≤ noteMaxLength (trim; empty → null). Error messages: `field: problem`, user-facing.
8. **Conversion** to `ManualMatchFields`: `combatScore = acs == null ? null : Math.round(acs * rounds)`, `damageDealt` likewise from adr; `excluded = manualExclusion(queueId, won+lost)`. `ManualMatchDto` converts back (acs = combatScore/rounds rounded to 1 decimal).
9. **Routes** (all `requireUser`, CSRF already global for POST/PUT/DELETE — confirm PUT is covered; add it if not):
   - `POST /manual-matches` → 201 ManualMatchDto; `'duplicate'` → 409 `duplicate` "An identical manual entry already exists."
   - `GET /manual-matches/template.csv` → header row of `MANUAL_CSV_COLUMNS` names + one example row using the first catalog map/agent names; attachment `valorant-analyzer-manual-template.csv`. Register before `/:id`.
   - `GET|PUT|DELETE /manual-matches/:id` (id = `manual-<uuid>`; bad format → 404). PUT duplicate → 409.
   - `DELETE /manual-matches` with body `{ confirm: true }` (else 400) → 204.
   - `POST /manual-matches/import` with JSON `ImportRequest`; route-level `express.json({ limit: '1.5mb' })` (keep the global default for everything else); `csv.length > MANUAL_LIMITS.importMaxBytes` → 400; more than `importMaxRows` data rows → 400; rate-limit with the `sensitive` limiter.
10. **CSV import** (`http/csvImport.ts`, pure functions, no deps): RFC 4180 parser (quoted fields, escaped quotes, commas/newlines inside quotes, CRLF/LF, UTF-8 BOM, trailing empty lines ignored; unterminated quote → whole-file 400 `validation` with the line number). Header names case-insensitive and trimmed; unknown columns → file-level error listing them; missing required columns → file-level error. Map/agent cells resolve by display name (case-insensitive, trimmed) or id. Blank optional cells → null. Strip a single leading `'` from cells (our export's formula-escaping). Each row → `manualInputSchema` → `ImportRowResult` with `line` = physical line number of the row start. Duplicates: within the file (same dedupe key as an earlier row) or already stored (`existingManualDedupeKeys`) → `'duplicate'`. **All-or-nothing:** if `dryRun` or any row is invalid → `imported: 0` and nothing is written; else `insertManualMatches` with the valid rows only (duplicates skipped) and `imported` = inserted count. File-level errors return 400 `ApiError` with code `validation` and a message naming the problem.
11. **Export CSV:** includes manual records; the `source` column comes from the record. Column definitions (`?definitions=1`) gain `source`.
12. **Public profile:** counts from both sources (competitive, non-excluded); `manualCount` = manual ones; append to `disclaimer`: ` Includes N manually entered matches.` when N > 0.
13. **Account unlink** (`DELETE /account-link`): unchanged behaviour; manual entries survive (T11 guarantees it).
14. `/sync` still requires a linked account.
