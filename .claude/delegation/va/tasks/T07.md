## Decisions already made (data minimization — important)
- **Only linked players' data is stored in relational tables.** No `match_participants` for other players. Match-level facts (map, queue, teams, rounds count) go on `matches`; the linked player's derived stats go in `player_match_records`; the linked player's per-round view in `player_rounds`. Full raw payloads (which contain other players) live only in `raw_payloads` with an `expires_at` for retention, used for reprocessing/debugging.
- No OAuth tokens or secrets in any table. Session tokens and share tokens are stored as SHA-256 hex hashes only.
- IDs: `uuid` with `defaultRandom()` except natural keys (Riot match id, puuid).
- Timestamps `timestamp with time zone`. Use `drizzle-orm/pg-core`.

## Tables (names exact; add indexes noted)
- `users`: id uuid pk, display_name text not null, is_demo boolean default false, settings jsonb default `{}`, created_at.
- `sessions`: token_hash text pk, user_id → users cascade, created_at, expires_at. idx user_id.
- `riot_accounts`: id uuid pk, user_id → users cascade **unique**, puuid text **unique** not null, game_name, tag_line, shard text not null, link_state text not null, consented_at, linked_at, last_synced_at, last_error text.
- `oauth_states`: state text pk, user_id → users cascade, expires_at.
- `content_items`: (kind text 'agent'|'map', id text) pk, name text, asset_path text null, updated_at. For maps, `id` = asset path is NOT assumed; store both.
- `raw_payloads`: id uuid pk, kind text ('match'|'matchlist'), source_key text (match id or puuid), schema_version text, payload jsonb, fetched_at, expires_at. idx (kind, source_key), idx expires_at.
- `matches`: match_id text pk, started_at, map_id, queue_id, patch null, season_id null, duration_ms int null, rounds_played int, is_completed bool, excluded text null, teams jsonb (NormalizedTeam[]), has_round_data bool, raw_payload_id → raw_payloads set null, fetched_at. idx started_at.
- `player_match_records`: (match_id → matches cascade, puuid) pk; every `PlayerMatchRecord` field as a column (snake_case; nullable where the type is nullable; performance_score int null); plus excluded text null. idx (puuid, started_at), idx (puuid, agent_id), idx (puuid, map_id).
- `player_rounds`: (match_id, puuid, round_number) pk, FK (match_id, puuid) → player_match_records cascade; won bool, result text, kills int, died bool, damage int, first_kill bool, first_death bool, planted bool, defused bool.
- `ingestion_jobs`: id uuid pk, user_id → users cascade, state text ('queued'|'running'|'succeeded'|'failed'), cursor int default 0, total int null, retry_count int default 0, error_category text null, error_message text null, created_at, started_at, finished_at. idx (user_id, state).
- `insight_feedback`: user_id → users cascade, finding_id text, action text, created_at; pk (user_id, finding_id).
- `share_links`: id uuid pk, user_id → users cascade, token_hash text unique, fields jsonb (ShareField[]), created_at, expires_at null, revoked_at null.
- `analysis_snapshots`: id uuid pk, user_id → users cascade, kind text ('insights'|'score'), version text, filter jsonb, result jsonb, created_at. idx (user_id, kind, created_at).

## Module API (`apps/api/src/db/index.ts` re-exports everything; names exact)

export type Db = PgDatabase<PgQueryResultHKT, typeof schema>;     // works for both drivers
export async function createPgliteDb(dataDir?: string): Promise<Db>;   // in-memory when undefined; runs migrations
export async function createNodePgDb(connectionString: string): Promise<{ db: Db; close(): Promise<void> }>; // runs migrations

getSessionUser(db, token): Promise<UserRow | null>                              // null if expired
deleteSession(db, token): Promise<void>
// riot account
getRiotAccount(db, userId): Promise<RiotAccountRow | null>

setLinkState(db, userId, state: LinkState, extra?: { lastError?: string | null; lastSyncedAt?: Date }): Promise<void>

// content

// raw payloads

// matches & records (all upserts idempotent: ON CONFLICT DO UPDATE)

// jobs

getJob(db, id, userId): Promise<JobRow | null>         // scoped to user
listQueuedJobs(db): Promise<JobRow[]>
updateJob(db, id, patch: Partial<Pick<JobRow, 'state'|'cursor'|'total'|'retryCount'|'errorCategory'|'errorMessage'|'startedAt'|'finishedAt'>>): Promise<void>
// feedback
saveFeedback(db, userId, findingId, action): Promise<void>   // upsert
listFeedback(db, userId): Promise<{ findingId: string; action: string }[]>
// share links
createShareLink(db, userId, fields: ShareField[], expiresAt: Date | null): Promise<{ row: ShareLinkRow; token: string }>
listShareLinks(db, userId): Promise<ShareLinkRow[]>

Map rows ↔ domain types in one place (`mappers.ts`): numeric columns, ISO strings for `startedAt` in PlayerMatchRecord, `performanceScore: null`.

## Steps
1. `schema.ts`, `drizzle.config.ts` (dialect postgresql, schema `./src/db/schema.ts`, out `./drizzle`). Generate migrations: `cd apps/api && npx drizzle-kit generate --name init` — commit the SQL.
2. Migration runner: use `migrate` from `drizzle-orm/pglite/migrator` / `drizzle-orm/node-postgres/migrator` with `migrationsFolder` resolved from `import.meta.url`.
3. Repositories in `repos/*.ts` or a few files; `index.ts` re-exports.
4. Tests with `createPgliteDb()` (fresh DB per test file or per test).

## Tests (`apps/api/test/db.test.ts`)
Upsert idempotency (same match + record twice → 1 row, updated values); listPlayerRecords ordering & excluded filtering; getPlayerMatch returns null for another puuid; session expiry; token hashes stored (raw token not in table); oauth state single-use + expiry; createOrGetActiveJob doesn't duplicate; share link revoke/expire/other-user revoke false; deleteUserMatchData removes the user's data but keeps a match still referenced by another linked player; purgeExpiredRawPayloads.
