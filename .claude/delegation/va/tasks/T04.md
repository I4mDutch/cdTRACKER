**Agent:** executor-sonnet · **Depends on:** none · **Wave:** 1

HTTP client with timeouts, bounded concurrency, rate-limit handling and retry/backoff.

## Interface (from types.ts)
```ts
export interface RiotClient {
  getMyAccount(accessToken: string): Promise<RiotAccountDto>;
  getMatchlist(puuid: string, shard: RiotShard): Promise<RiotMatchlistDto>;
  getMatch(matchId: string, shard: RiotShard): Promise<unknown>;
  getContent(shard: RiotShard): Promise<RiotContentDto>;
}
class RiotApiError(message, category: 'auth'|'forbidden'|'not_found'|'rate_limited'|'upstream'|'network'|'timeout', status: number, retryAfterMs: number|null) { get retryable(): boolean }
```

## Steps
1. `fixtureClient.ts`: `export class FixtureRiotClient implements RiotClient { constructor(opts: { dir: string }) }`. Reads JSON with `fs/promises`. Unknown token → `RiotApiError('...', 'auth', 401)`. Missing matchlist/match file → `'not_found', 404`. Validate path segments (`/^[A-Za-z0-9-]+$/`) before joining to prevent path traversal → `not_found` otherwise. Also export `export const DEFAULT_FIXTURE_DIR` resolved from `import.meta.url` to `<repo>/fixtures/riot`.
2. `limiter.ts`: `export function createLimiter(maxConcurrent: number): <T>(fn: () => Promise<T>) => Promise<T>` (simple FIFO semaphore, no deps).
3. `httpClient.ts`: `export class HttpRiotClient implements RiotClient` with
   ```ts
   constructor(opts: {
     apiKey: string;                         // X-Riot-Token header; never logged
     accountRegion?: 'americas' | 'europe' | 'asia';   // for ACCOUNT-V1, default 'americas'
     fetchImpl?: typeof fetch;               // injectable for tests
     timeoutMs?: number;                     // default 10_000, via AbortController
     maxConcurrent?: number;                 // default 4
     maxRetries?: number;                    // default 3
     baseBackoffMs?: number;                 // default 500; exponential w/ full jitter, cap 30_000
     sleep?: (ms: number) => Promise<void>;  // injectable for tests
   })
   ```
   URLs: account `https://{accountRegion}.api.riotgames.com/riot/account/v1/accounts/me` with `Authorization: Bearer <accessToken>` (no X-Riot-Token on this call); matchlist `https://{shard}.api.riotgames.com/val/match/v1/matchlists/by-puuid/{encodeURIComponent(puuid)}`; match `/val/match/v1/matches/{id}`; content `/val/content/v1/contents?locale=en-US`.
   Status mapping: 401→auth, 403→forbidden, 404→not_found, 429→rate_limited (parse `Retry-After` seconds → ms), 5xx→upstream, abort→timeout, fetch throw→network. Retry only `retryable` errors up to maxRetries; on 429 wait `retryAfterMs` if present else backoff. Error messages must not include the API key or access token.
4. `index.ts`: re-export `types.ts`, both clients, `createLimiter`.

## Tests (`apps/api/test/riot.test.ts`)
Use temporary fixture dirs created in the test (`fs.mkdtemp`) with tiny hand-written JSON. Fixture client: happy paths, unknown token, missing match, traversal attempt `../x`. HTTP client with a fake `fetchImpl` and instant `sleep`: correct URL + headers, 404 not retried, 429 with Retry-After retried then succeeds (sleep called with 2000 for `Retry-After: 2`), 5xx retried up to maxRetries then throws upstream, timeout → timeout category, concurrency never exceeds maxConcurrent, error message excludes the key.
