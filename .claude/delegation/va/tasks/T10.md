# T10: Core support for record sources and per-field coverage

**Agent:** executor-sonnet · **Depends on:** none · **Wave:** 5 (manual entry feature)

## Goal
Manual entries (typed or CSV-imported by the user) flow through the same aggregation and analysis as Riot matches.
They have partial data: e.g. ADR known but first kills unknown, or vice versa. Make core handle that correctly,
and add the `source` field/filter.

## Steps
1. `toPlayerRecord` sets `source: 'riot'`.
2. `filterRecords`: honor `filter.source` (exact match; undefined/empty = both).
3. `computeStatLine` — replace the current "round data" pooling (which treats null headshots/firstKills as 0 inside a record that has damageDealt) with **independent per-metric record sets**:
   - adr: records with `damageDealt !== null`; denominator their rounds. `coverage.roundData` / `roundDataRounds` = that set.
   - headshotPct: records where `headshots`, `bodyshots`, `legshots` are all non-null.
   - firstKillsPerRound / firstDeathsPerRound / firstDuelWinRate: records where `firstKills !== null && firstDeaths !== null`; per-round denominator = those records' rounds. `coverage.firstDuel` / `firstDuelRounds` = that set.
   - A record missing one field must not dilute another metric.
4. `computeTrend`: `sample` logic unchanged in spirit (records contributing a non-null value for the metric).
5. Analysis:
   - `first_duel` finding: gate and compute using records where firstKills and firstDeaths are non-null (use `coverage.firstDuelRounds` ≥ minRounds and the duel count ≥ 30); `sampleRounds` = firstDuelRounds.
   - Score `objective` component availability stays `plants !== null` (manual entries have no plants → objective unavailable when they are >20% of window/history, which is correct). `impact` stays combatScore-based.
   - `method` strings: if any subject record has `source === 'manual'`, append `" Includes N manual entries."` to the finding's `method`. The score is unchanged (the API reports source counts separately).
6. Update every test helper that builds `PlayerMatchRecord` to include `source`. Add tests: source filter; mixed records where one has damageDealt but null firstKills and another has firstKills but null damageDealt → each metric uses only its own set (hand-check arithmetic in comments); coverage fields; first_duel gating with manual records lacking first-duel data; method suffix; `manualOutcome` / `manualExclusion` cases (remake boundary at 4 rounds, unsupported queue, draw).
