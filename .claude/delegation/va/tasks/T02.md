## Rules
**parsePatch:** match `/^release-(\d+)\.(\d+)/`; return `${Number(major)}.${minor}` (major loses leading zeros, minor kept exactly as given). `"release-08.11-shipping-6-2545312"` → `"8.11"`, `"release-09.06-…"` → `"9.06"`, `"release-10.02-…"` → `"10.02"`. No match / null / undefined → null.

**normalizeMatch** — `raw` is untrusted `unknown`. Use hand-written type guards (zod is NOT a dependency of core; do not add it).
- Fatal (`ok:false`): not an object; missing/invalid `matchInfo`, `matchInfo.matchId` (non-empty string), `matchInfo.mapId`, `matchInfo.gameStartMillis` (finite number), `matchInfo.queueId` (string), `matchInfo.isCompleted` (boolean); `players` not an array or empty; a player without string `puuid`/`teamId`/`characterId`.
- `startedAt` = `new Date(gameStartMillis).toISOString()`. `durationMs` = `gameLengthMillis` if finite number else null. `seasonId` string or null. `patch` = parsePatch(gameVersion).
- Participants: kills/deaths/assists/roundsPlayed/combatScore (`stats.score`) are null when `stats` missing or the individual value isn't a finite non-negative number (emit a `warning` issue `missing_player_stats`).
- Teams: from `teams` (null/absent → `[]` + warning `missing_teams`). `roundsPlayed` = max team roundsPlayed, else `roundResults.length`, else 0.
- Rounds: `roundResults` absent/null/empty → `rounds: []` (warning `missing_round_data` only when absent/null, not when empty array… emit it in both cases, code `missing_round_data`). Otherwise roundNumber = roundNum + 1; kills flattened from all `playerStats[].kills`, sorted by `timeSinceRoundStartMillis` asc, **deduplicated** (same killer+victim+time); damage = per `playerStats[]` entry, sums over its `damage[]`. Skip malformed sub-entries with a warning rather than failing.
- Consistency checks (warnings): `team_round_mismatch` when count of rounds won per team ≠ team.roundsWon (only when rounds non-empty).
- `excluded` (first matching rule wins):
  1. `!isCompleted` → `'incomplete'`
  2. completed and `roundsPlayed <= config.remakeMaxRounds` → `'remake'`
  3. teams.length !== 2 or more than one team `won` → `'inconsistent_teams'`
  4. queueId not in `config.supportedQueues` → `'unsupported_queue'`
  5. else null
- Never throw for bad data; always return a NormalizeResult. Don't mutate input.

**toPlayerRecord(match, puuid)**
- Participant not found → null.
- If participant kills/deaths/assists is null → null (cannot build a record; caller treats as `player_missing`).
- `outcome`: player's team `won` → 'win'; other team won → 'loss'; no team won → 'draw'.
- `roundsWon` = player team roundsWon (fallback: count rounds won from `rounds`), `roundsLost` = opposing team roundsWon (same fallback), `roundsPlayed` = participant.roundsPlayed ?? match.roundsPlayed.
- If `match.rounds.length === 0`: damageDealt, headshots, bodyshots, legshots, firstKills, firstDeaths, plants, defuses all null.
- Else: sums across rounds of player's damage entry (0 if player has no entry that round); firstKills = rounds where `kills[0].killer === puuid`; firstDeaths = rounds where `kills[0].victim === puuid`; plants/defuses = rounds where planter/defuser === puuid.
- `performanceScore: null` always.
